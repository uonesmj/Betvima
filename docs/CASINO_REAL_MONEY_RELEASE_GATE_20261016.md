## USD/native-wallet invariants

- Supplier bet and win use integer USD cents, minimum normal bet 20 cents.
- A BetVima USD wallet keeps cents. IRT keeps toman ledger units and IRR
  keeps rial ledger units; conversion is server-only with a timestamped
  Arzhaam rate. A fiat debit rounds up; winnings round down; cancellation
  returns the **exact original local debit**, not today's equivalent.
- Deduplication keys, receipt and ledger posting must be committed in
  a single transaction. Replaying the same `call_id` with any changed
  transaction identity must not mutate the wallet.
- Provider prepayment/credit is **not** a user's wallet balance.
- Never expose API credentials or game launch session URLs in logs.
